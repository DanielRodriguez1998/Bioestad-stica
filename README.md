# Bioestad-stica
Este repositorio reúne una colección completa de scripts en R para resolver ejercicios prácticos de bioestadística, cubriendo pruebas paramétricas y no paramétricas, análisis de varianza, inferencia de proporciones, pruebas de normalidad, regresión y comparación de grupos.

Es ideal como referencia para estudiantes, investigadores o profesionales en ciencias biológicas, médicas y sociales que necesitan aplicar análisis estadísticos en datos experimentales o clínicos.
